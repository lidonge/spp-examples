# 第一篇 角色与服务的基本模型

> © 2026 S++ project contributors. All rights reserved. [Book copyright](https://github.com/lidonge/spp-examples/blob/main/book/COPYRIGHT.md).

从一个人在购买、付款和经营中的不同身份开始，认识参与者、行为、角色、服务与合约。用转账和下单解释服务的分解、最小颗粒度、组合，并通过角色多态复用计算、校验与完整场景。同时说明查询、计算、校验与普通更新的特点及协作规则。读完这一篇，应能用“谁以什么身份完成什么行为”描述一项业务。
