# 第七篇 进阶案例与架构方法

> © 2026 S++ project contributors. All rights reserved. [Book copyright](https://github.com/lidonge/spp-examples/blob/main/book/COPYRIGHT.md).

用银行存款与冲正展示复杂规则，随后讨论系统迁移、设计评审与复杂需求的表达能力。区分面向角色的建模方法、商业服务架构和当前语言实现，并用哈希表说明简单概念怎样构成复杂算法。把案例中的参与身份、行为、事实归属与执行证据提炼为可复用的方法。
